## Purpose
Get a working Java toolchain and a Git repo, and start the two requests with a 24-48 hour wait.

## Learn first (~45 min)
- What JDK vs JRE vs JVM are
- What Maven is: `pom.xml`, `src/main/java`, `src/test/java`, `mvn compile/test/package`
- Git basics: init, add, commit, remote, push

## Tasks
### Task 1 — Install and verify
Install JDK 21, Maven, an IDE (IntelliJ Community or VS Code + Java extension), and Git.
**Evidence:** screenshot of `java -version`, `mvn -v`, `git --version`.

### Task 2 — First Maven project
Create a Maven project (`groupId` of your choice) with a `Main` class that prints a message. Build and run it from the command line.
**Evidence:** screenshot of `mvn package` success and the program output.

### Task 3 — Git and GitHub
Create a **private** GitHub repo for this program. Add a `.gitignore` for Java (`target/`, `.idea/`, `*.csv`, `*.zip`, `config.json`). Push.
**Evidence:** screenshot of the repo page.
