# Assignment 4 — Collections, Exceptions, Streams

**Day 4 · Sat 14 Nov** · Difficulty: ★★★☆☆

## Purpose
Handle data sets and errors properly; this is where real backend code starts.

## Learn first (~1 h)
`List/Set/Map` and when to use each, generics, checked vs unchecked exceptions, `try/catch/finally`, try-with-resources, custom exceptions, streams (`filter/map/collect/groupingBy`).

## Tasks
### Task 1 — Collections
Count unique words in a sentence using a `Set`, then count frequencies with a `Map`.
### Task 2 — Exceptions
Write a method that parses an integer from a string; define a custom `InvalidInputException`. Show catch vs propagate.
### Task 3 — Streams
Given a list of `Tweet` records: filter by keyword, map to text, sort by date, group by month.
### Task 4 — Word-frequency tool (hardest)
Read a text file path from args, print the top 10 words. Missing file and empty file must produce clear errors (custom exception), not stack traces. Use try-with-resources.

**Evidence:** code + output, including the error cases.

## Quiz (end of day, with tutor)
5 questions on collections choice, exception types, and stream pitfalls.
